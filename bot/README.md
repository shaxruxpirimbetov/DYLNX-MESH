# Mesh - DYLNX

```
Mesh_v2/       Django-бэкенд (доработан) + 3 страницы стикера в templates/
mesh_bot/      Telegram-бот на aiogram 3
admin_panel/   Админ-панель, один файл index.html
```

## Как всё связано

1. Админ создаёт стикеры в панели и печатает карточки: QR и секретный код.
2. Покупатель сканирует свой QR и попадает на `unactive_qr.html`. Там кнопка «Это мой стикер — активировать», она ведёт в бота (`?start=a_<uuid>`). Бот спрашивает код с карточки, а потом, по желанию, номер. После этого вызывается `PATCH /api/mesh/activate/<uuid>/`.
3. Прохожий сканирует QR активного стикера и попадает на `open_mesh.html`. Через 5 секунд (или сразу по нажатию кнопки) страница открывает бота (`?start=<uuid>`). Человек выбирает причину или пишет своё, и бот сразу пересылает это владельцу.
4. Владелец отвечает в боте. Аккаунты обеих сторон скрыты: бот копирует сообщения через `copy_message`, без пометки «переслано от».
5. Каждое сообщение сохраняется в `/api/message/`. Поллер бота раз в 3 секунды проверяет API на новые сообщения, которые пришли не через бота. Например, если админ написал владельцу из панели, такое сообщение приходит владельцу в Telegram. Это замена WebSocket.

## Бэкенд: что изменилось

- `.env`: новые переменные `TELEGRAM_BOT_USERNAME=ИмяБота` (без @) и `MESH_BUY_URL=https://...` (необязательно).
- Миграция: `python manage.py migrate`. `Message.telegram_id` теперь `BigIntegerField`, потому что ID в Telegram давно не помещаются в int32.
- `OpenMeshAPIView` больше не отдаёт `telegram_id` владельца в HTML. Если `telegram_id` пустой или срок `until` истёк, показывается `unactive_qr`. Неизвестный UUID отдаёт 404 и страницу `invalid_uuid`.
- Активация: если стикер уже привязан к другому Telegram, возвращается 409. Передать стикер можно только через «Отвязать» в панели. Пароль в ответе больше не возвращается.
- `/api/message/` закрыт для анонимов, теперь доступ только у staff. Раньше любой мог прочитать всю анонимную переписку.
- Staff не лимитируется троттлингом, иначе бот упирался бы в лимит 100/min.
- Новые эндпоинты: `GET /api/mesh/stats/`, `GET|PATCH /api/mesh/uuid/<uuid>/`, `POST /api/mesh/<pk>/regenerate-qr/`.
- Новые фильтры: `?search= ?status=active|inactive|expired ?telegram_id= ?until_lte= ?page_size=`. У сообщений: `?mesh= ?after_id= ?search=`.
- Если загрузка QR в R2 упала, стикер всё равно создаётся. QR можно перегенерировать из панели.
- `UserSerializer` больше не отдаёт хэш пароля. Пользователей можно редактировать и удалять.

## Бот

```bash
cd mesh_bot
pip install -r requirements.txt
cp .env.example .env     # BOT_TOKEN, API_URL, API_USERNAME, API_PASSWORD
python bot.py
```

Боту нужен аккаунт на бэкенде с `is_staff=True`. Создать его можно в панели («Пользователи» → «Добавить», галочка Staff) или через `createsuperuser`.

## Админ-панель

Откройте `admin_panel/index.html` с любого хостинга, например Vercel или GitHub Pages. При входе укажите адрес API. Домен панели нужно добавить в `CORS_ALLOWED_ORIGINS` бэкенда. Если `DEBUG=True`, разрешены все домены.
